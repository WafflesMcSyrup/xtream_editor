## Xtream Editor 6.4

Small quality-of-life update.

**What's new**
- **Label your lists**: the Fetch from Server and Second login dialogs have a new **Label** box (like "Provider A - Home"). It's saved in the project, shows in the window title, and the master list builder uses it to name each source.
- **File > Recent projects**: the last 5 projects you opened or saved, with their labels. Clear list is at the bottom.
- **Category manager: Remove Country Code** button. Takes `|EN|`, `EN |` or `[UK]` style prefixes off the New name column, for the selected rows or every row shown. Combine it with Proper Case. Nothing changes until you press Apply.

**Getting it**
- Windows: download the programs from the assets below, no Python needed. Windows may show a SmartScreen warning because the apps aren't code-signed; choose *More info > Run anyway*.
- Any system: grab the source zip and run `python main.py` (needs Python 3.10+ and `pip install -r requirements.txt`).

Full list in [CHANGELOG.md](CHANGELOG.md).
